## Getting Started

### Prerequisites

- Git
- A runtime appropriate for the stack listed above

### Installation

```bash
git clone https://github.com/RaghavSobti37/woTeaT.git
cd woTeaT
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
